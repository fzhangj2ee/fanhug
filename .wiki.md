# Project Summary
FanHug is a web application designed to enhance the live sports prediction experience with an intuitive interface. Users can securely register using email/password or OAuth2 social accounts and make payments through Stripe. The application leverages The Odds API for real-time prediction data, featuring automated pick grading, live updates, and an admin dashboard for user management. FanHug promotes responsible gaming through a play money feature, allowing users to make predictions without financial risk, and includes a donation page to support its mission of restoring integrity in sports.

# Project Module Description
- **Authentication System**: 
  - Supports email/password and OAuth2 social login.
  - Manages sessions and secure routes.
  - Enables user profile management.

- **Payment Processing**: 
  - Integrates with Stripe for secure transactions.
  - Provides transaction history and confirmations.

- **Live Predictions**: 
  - Offers real-time odds and score updates.
  - Users can make picks on ongoing games.
  - Automates grading of picks after games finish.

- **User Profile Management**: 
  - Accessible from the user icon dropdown.
  - Displays and allows editing of user information.

- **Admin Dashboard**:
  - Lists all registered users with detailed views.
  - Manages user data and prediction activity.
  - Displays all user bets, ensuring visibility of all users and their betting statistics.
  - Fetches all bets directly from Supabase.

- **User Messaging System**:
  - Users can send messages to admins.
  - Admins can view messages with read/unread indicators.

- **Donation Page**:
  - Invites professional players affected by real-money betting to support the mission of restoring clean, fair sports.

- **Pick Slip Management**:
  - Supports accumulation of multiple picks.
  - Recent picks show in "My Picks" after placement.

- **Password Reset Flow**:
  - Allows users to request a password reset.

# Usage
To get started with the project, follow these steps:
1. Clone the repository.
2. Install dependencies using the package manager.
3. Create a `.env.local` file and configure your environment variables, including the Odds API key.
4. Build and run the application.
